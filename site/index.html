A shoot doesn’t end when you stop shooting.

It ends weeks later, when you sit down with the folder. A file manager makes you open a photo, drag it somewhere, and remember what you already decided. Ten minutes in you’re not culling, you’re doing inventory.

Open
A preview window, sized wrong, one photo behind.
Drag
A “best” folder you don’t trust, because you lost count halfway.
Resume
You stopped at photo 200 last week. Or was it 180?

One photo. One question: keep it?

The photo gets the screen

No part of the interface covers the image. Press F and the bars go away too.

Check sharpness before you decide

Space shows the photo at 1:1, one image pixel per screen pixel. Space again fits it back.

The keys do the work

Right keeps, left discards, U takes back the last decision. The next photo is already loaded.

Stop when you want

Every decision is saved the moment you make it. Close the window and come back next week. The review is where you left it.

What PhotoTriage never does.

It never deletes
The app has no delete action.
It never touches a discarded photo
Not moved, not tagged, not renamed. A discard is a decision, not an edit.
It never overwrites
A taken name becomes IMG_0412_1.JPG.
It never goes online
The server is bound to 127.0.0.1 and no option changes that.
state.json, written as you go. Nothing to save by hand.

Know the limits before you install.

It is a first pass

One photo at a time is fast for a clear yes or no. It does not put near-identical frames side by side.

It shows JPEG, PNG, WebP, GIF, BMP and TIFF

No HEIC. A RAW file is not displayed. It travels with the JPEG of the same name, so a RAW-only folder has nothing to review.

Undo goes back one step at a time

To change an older decision, undo your way back to it.

Zoom resets on every photo

No ratings, no edits

Keep or discard is the whole vocabulary.

Get it on GitHub 

git clone https://github.com/LaiqianDS/phototriage.git
cd phototriage
uv sync
uv run phototriage ~/Pictures/2024

You need uv. It installs Python for you. The app opens at 127.0.0.1:8000.
